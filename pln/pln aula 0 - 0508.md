**Processamento da Linguagem Natural:**
	-> É um ramo da Inteligencia Artificial que permite transformar  dados em conhecimento útil a partir da interpretação e extração de características de bases de texto. 
	-> Para que seja possível criar sistemas utilizando técnicas de PLN será necessário compreender conceitos da Computação e Linguística 
	-> Os sistemas em PLN podem ser divididos em 4 abordagens principais: [[ABORDAGENS DO PLN 0508| Simbólica ]], **Estatística**, **Conexionista** e **Híbrida**
	-> Emergiu como uma ferramenta importante para entender e interagir com a linguagem humana

> [!NOTE]
> -  **==Linguagem Natural==**: conjunto de símbolos que se torna comum pela grande utilização
> 

"Da mesma forma que uma criança aprende, o computador também, e esse é o processo do PLN"

- A base de dados é a fundamentação do PLN, ela é o coração que permite o avanço do sistema, fornecendo conhecimento da linguagem do sistema para interpretação, resposta, processar informações ...
- processar é justamente o trabalho de pegar palavra por palavra e associar suas equivalentes ao outro idioma (em um exemplo de tradução de um idioma para outro)
- Resposta: conhecimento útil
- **A qualidade da base de dados é diretamente proporcional à qualidade da resposta**
