1- Processamento de Linguagem Natural,  é a solução encontrada para o desafio que o computador e o ser humano enfrentavam para comunicar-se entre si, uma vez que o computador utiliza linguagem binária. 

2- A abordagem simbolica se trata de sistemas simples baseados em regras. Estatística, abrange sistemas, por calculo de propabilidade e frequencia, como uma barra de pesquisa de busca. Conexionista, abrange sistemas como tradutores, chatbots, de dados que possuem dependencia entre si, chamados de conexao, utilizando rede neural. Híbrida, utiliza mais de uma abordagem.

3- Tokenizacao é o ato de separar palavras em tokens, nao podemos enviar um texto inteiro, entao, devemos quebrar os textos em menores partes.

4- Stopwords sao as palavras repetitivas que nao agregam valor ao contexto, mantendo no vocabulario apenas o que vale a pena

5- radicalizacao é ter apenas a raiz da palavra e lematizacao é ter o lema da palavra, a forma natural da palavra como se encontraria no dicionario

6- Letras se mantem minusculas e pontuacoes sao retiradas para nao ter varias formas da mesma palavra, e assim o computador vai identificar que é a mesma palavra e nao tera redundancias armazenadas

7 - Bag of words é necessario para transformar em valore snumerico e poder usar em algoritmos como o perceptron.
