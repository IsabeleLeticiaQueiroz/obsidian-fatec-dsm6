# 1. Truques de formatação

### Marca-texto

Digite dois sinais de igual antes e depois.

`==Conceito importante==`

Resultado: Conceito importante

### Negrito

`**Velocidade média**`

Resultado: Velocidade média

### Itálico

`*Atenção a este detalhe*`

Resultado: Atenção a este detalhe

### Tachado

`~~Resposta errada~~`

Resultado: Resposta errada

### Código

`` `H₂O` ``

Resultado: `H₂O`

# 2. Caixinhas para organizar o conteúdo

Você pode criar títulos e subtítulos usando `#`.

# Química

## Ligações químicas

### Ligação covalente

Cada # adicional diminui o nível do título.

E pode criar listas de tarefas usando:

`- [ ] Estudar ligações químicas`

`- [x] Revisar tabela periódica`

Estudar ligações químicas

Revisar tabela periódica

Isso é ótimo para acompanhar o que você já estudou e o que ainda precisa revisar.

# 3. Caixas de aviso coloridas

Esse é um dos meus favoritos para montar resumos. O Obsidian chama esse recurso de callouts.

Você escreve, por exemplo:

&gt; !important!important Conceito importante &gt; A velocidade média depende do deslocamento e do intervalo de tempo.

O resultado fica assim:

Conceito importante

A velocidade média depende do deslocamento e do intervalo de tempo.

Existem vários tipos. Basta trocar o nome depois de `[!`:

`[!info]` — Informação

Para explicações complementares.

`[!tip]` — Dica

Para macetes de prova.

`[!warning]` — Cuidado

Para pegadinhas do ENEM.

`[!question]` — Dúvida

Para perguntas que você ainda não sabe responder.

# 4. Conectar suas anotações

Esse recurso é uma das maiores vantagens do Obsidian.

Se você escrever:

`[[Ligações químicas]]`

O Obsidian cria um link para uma nota chamada Ligações químicas. Se ela ainda não existir, você pode criá-la ao abrir o link.

Você também pode vincular conceitos dentro de uma frase:

> A polaridade das moléculas depende de sua \[Geometriamolecular\[Geometria molecular].

E pode criar links para uma seção específica de outra nota:

`[[Química#Ligações químicas]]`

Isso ajuda muito quando um assunto depende de outro. Por exemplo, geometria molecular, polaridade e forças intermoleculares.

# 5. Escrever fórmulas matemáticas bonitas

Em vez de deixar as fórmulas como texto comum, você pode usar LaTeX.

Para uma fórmula no meio do texto:

`A velocidade média é $v = \frac{\Delta s}{\Delta t}$.`
$v = \frac{\Delta s}{\Delta t}$

Para uma fórmula centralizada em uma linha separada:

Digite:

\\displaystyle v\_m \= \\frac{\\Delta s}{\\Delta t}

O resultado será:

vm=ΔsΔtv_m = \frac{\Delta s}{\Delta t}vm=ΔtΔs

É excelente para Física e Matemática. O Obsidian também permite escrever índices e cargas químicas com LaTeX, como SO2SO_2SO2, SO3SO_3SO3 e Ca2+Ca^{2+}Ca2+.

# 6. Criar tabelas sem sair do teclado

Você pode escrever uma tabela assim:

| Grandeza | Símbolo | Unidade | |---|---|---| | Distância | d | m | | Tempo | t | s | | Velocidade | v | m/s |

O resultado fica organizado em colunas. É útil para comparar conceitos, reunir fórmulas e registrar propriedades químicas.

# 7. Dobrar e esconder partes das anotações

Você pode usar títulos para organizar uma nota longa e recolher as seções pelo ícone que aparece ao lado do título.

Por exemplo:

Ligações químicas

Ligação iônica

Ligação covalente

Ligação metálica

Você pode recolher o conteúdo para deixar a nota mais limpa e abri-lo quando precisar revisar.
