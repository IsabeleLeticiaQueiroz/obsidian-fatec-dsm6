##### Amazon Virtual Private Cloud
Quando temos duas ou mais instâncias dentro da Aws, há a necessidade dessas maquinas conversarem, não pelo ip publico, mas pelo local.
Vamos supor que nessas instancias criadas haja a necessidade de uma comunicação como se fosse uma rede local, é necessário criar uma VPC.
- Tudo através do ip local, a range você monta do jeito que quiser
- o objetivo de fato é criar uma rede local dentro da própria aws
- rede virtual isolada é o nome correto para essa rede local.

``Para criar uma VPC, há a necessidade:``
- VPC
- Subnet Mask
- Gateway da internet
- Tabela de rotas

``Criação da VPC
Configuração:
- Somente VPC
- escolher nome, geralmente relacionado ao nome da empresa
- professor normalmente usa 10.12.27

``Subnet Mask
- ao clicar em subnet mask, voce precisa selecionar a VPC que foi criada atraves do select.
- ao escolher ela, automaticamente ja vem a range que foi escolhida por voce quando criou a vpc
- informar nome da subnet (subnet_empresa) e a range
- a range da subnet deve ser a mesma faixa da informada na vpc

``Criando Gateway de internet
- Gateway é o caminho para a internet
- é o que faz o ip local sair para internet
- ao clicar em gateway da internet voce passa para a proxima etapa
- colocar nome (gateway_empresa), clicar em criar
- precisamos associar o gateway a uma vpc
- em vpc, gateway de internet, botão ações, associar a vpc

``Tabela de rotas
- criar tabela de rotas
- informar nome (rotas_empresa), associar a uma vpc.
- em tabela de rotas no menu, selecione a tabela de rotas criada, clique em editar rotas
- por rede local 0.0.0.0/0, local, gateway DA internet, embaixo por a vpc que voce quer associar a rota, salvar alteracoes
- associar as rotas a subnet, em tabelas de rotas novamente, ir na aba associacoes de subredes e editar, selecionar a tabela de rotas, salvar
