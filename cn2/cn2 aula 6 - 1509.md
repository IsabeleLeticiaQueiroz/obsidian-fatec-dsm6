###### 1. Preparar os wallpapers

- Escolhemos **3 papéis de parede**.
- Colocamos os arquivos dentro do **Windows Server 2025**.
- É importante saber fazer **arrastar e soltar (drag and drop)** arquivos do computador para dentro da VM.
- Na raiz do **C:**, criamos a pasta:  
    `C:\Wallpaper`
- Colocamos dentro dela uma cópia dos 3 wallpapers.

---
###### 2. Compartilhar a pasta Wallpaper

Na pasta `C:\Wallpaper`:

1. Botão direito → **Properties**.
2. Aba **Sharing**.
3. Clicar em **Share this folder**.
4. Em **Security**, adicionar **Everyone**.

Assim, os computadores/usuários da rede poderão acessar os wallpapers pelo servidor.

---
###### 3. Criar GPO para o Wallpaper

No **Group Policy Management**:

1. Botão direito no domínio `nome.local`.
2. **Create a GPO in this domain, and Link it here**.
3. Nomear como **Wallpaper**.
4. Botão direito no GPO criado → **Edit**.
5. Ir em:

**User Configuration → Administrative Templates → Desktop → Desktop**

6. Abrir **Desktop Wallpaper**.
7. Marcar **Enabled**.
8. No caminho do wallpaper, colocar:

`\\IP_DO_SERVIDOR\Wallpaper\wallpaper-1.jpg`

> O caminho usa o **IP do servidor + nome da pasta compartilhada**.

---
###### 4. Criar GPO para mensagem de login

Criar outro GPO e editar:

**Computer Configuration → Windows Settings → Security Settings → Local Policies → Security Options**

Procurar:

- **Interactive logon: Message title for users attempting to log on**
- **Interactive logon: Message text for users attempting to log on**

Em cada uma:

1. Abrir com duplo clique.
2. Marcar **Define this policy setting**.
3. Escrever a mensagem desejada.
